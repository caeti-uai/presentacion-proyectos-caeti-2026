# Presentación de proyectos CAETI 2026

Presentación web interactiva de 15 escenas para una exposición de 15 minutos sobre el proyecto **Arquitectura de Software para la Transformación hacia Sistemas Adaptativos Inteligentes** y el ecosistema de proyectos de investigación del CAETI, UAI Rosario.

## Uso

```bash
npm install
npm run dev
```

Controles durante la presentación:

- Flechas izquierda/derecha, barra espaciadora o Page Up/Page Down para navegar.
- Tecla `F` para pantalla completa.
- `Esc` para cerrar la ficha de un proyecto.

## Material visual

Las escenas 6 y 7 incorporan capturas reales del entorno colaborativo y de Odoo. Las fichas dinámicas muestran retratos de directores e investigadores disponibles en el material fuente. La escena de Hiperproductividad conecta la adaptación con ciclos de trabajo que acumulan contexto y evidencia.

La identidad visual toma como referencia los colores institucionales publicados por la UAI y presenta sobre fondo blanco la misión, la visión, las líneas de investigación y la comunidad del CAETI Rosario.
