# Presentación de proyectos CAETI 2026

Presentación web interactiva de 14 escenas para una exposición de 15 minutos sobre el proyecto **Arquitectura de Software para la Transformación hacia Sistemas Adaptativos Inteligentes** y el ecosistema de proyectos de investigación del CAETI, UAI Rosario.

## Uso

```bash
npm install
npm run dev
```

Controles durante la presentación:

- Flechas izquierda/derecha, barra espaciadora o Page Up/Page Down para navegar.
- Tecla `F` para pantalla completa.
- `Esc` para cerrar la ficha de un proyecto.

## Material visual

La escena 6 incorpora una captura real del entorno colaborativo. La escena 7 contiene una galería interactiva de Hiperproductividad. Las fichas dinámicas muestran retratos de directores e investigadores disponibles en el material fuente.

Cada ficha de proyecto reúne dirección, equipo, objetivo y referencias APA de las publicaciones disponibles en el material fuente. La galería de Hiperproductividad presenta agentes, configuración, equipos, canales colaborativos, oficina virtual, cerebro organizacional, tablero y motores de agentes.

La identidad visual toma como referencia los colores institucionales publicados por la UAI y presenta sobre fondo blanco la misión, la visión, las líneas de investigación y la comunidad del CAETI Rosario.
